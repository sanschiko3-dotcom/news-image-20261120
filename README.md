# The World Today

A deterministic, 1024 × 1024 newspaper front page summarizing the supplied world-news facts for Friday, 20 November 2026. Original Pillow drawing code renders real DejaVu TTF text and geometric illustrations. The supplied facts are the editorial input.

Run `python3 render.py` to regenerate `assets/entry.png` (requires Pillow and system DejaVu fonts). Run `python3 main.py` to copy the bundled image to `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to choose another destination. The entrypoint uses only the Python standard library and requires no network access.
